## Пересчёт после вражеских баз (TASK-38)

Точки входа заменены вражескими базами: каждая шлёт только свои типы врагов и получает новые типы по волнам (design.md §5). Состав и размер волн не менялись, но часть групп пришлось перевести на другую базу — туда, где их тип доступен. Направления ударов сместились, и два места просели:

| «Укрепрайон» сузился до трёх составов | Из шести выигрышных составов осталось три, запас у двух — 1–4 из 44 | Прочность объекта 44 → 47: четыре состава, без F-16 проходит A-10 + Growler + E-3 |

Что изменилось и оставлено как есть:

- «Укрепрайон» без F-16 теперь проходит только A-10 + Growler + E-3 (раньше — A-10 + Growler с любой третьей группой); причина не разбиралась.
- «Горный перевал» надёжно проходит только F-16 + Growler + KC-135; F-16 + Growler + E-3 — 4 победы из 5.
- C-130 входит в выигрышные составы двух первых миссий; в «Укрепрайоне» F-16 + A-10 + C-130 выигрывает 1 раз из 5.

## Пересчёт после рельефа-преграды (TASK-39)

Во всех шести миссиях появился рельеф: наземные враги обходят воду и горы, все враги — высокие хребты (design.md §5). Числа групп, врагов и миссий не менялись; условия `src/content/balance.test.ts` выполняются без правок. Что сместилось (5 сидов):

| Миссия | До рельефа | После |
|---|---|---|
| Укрепрайон | 4 выигрышных состава | 3: F-16 + A-10 + KC-135 теперь 4 победы из 5 (остаток 3%) |
| Речной караван | 2 выигрышных состава | 1: F-16 + A-10 + E-3 больше не выигрывает; остался F-16 + A-10 + Growler с остатком 21% |
| Горный перевал | 1 надёжный состав | Без изменений: F-16 + Growler + KC-135; ещё три состава выигрывают 1 раз из 5 |
| Остальные | — | Те же выигрышные составы, остаток прочности в пределах ±4 п.п. |

Оставлено как есть: «Радарный пост», «Речной караван» и «Горный перевал» проходятся ботом ровно одним составом каждая — запаса нет, следующая правка контента может оставить миссию без выигрышного состава.

## Итог по критериям

- Ни один состав не выигрывает все миссии: лучший проходит 4 из 6. «Радарный пост» требует ДРЛО, «Горный перевал» — Growler с заправщиком.
- Каждая из шести групп входит в выигрышные составы, и ни одна не обязательна во всех миссиях.
- Первая миссия проходится стартовым составом без покупок, если двигать зоны; первой награды хватает на любую группу.
- Валюты одного прохода кампании хватает на все группы и примерно на две трети улучшений; остальное — повторные вылеты за звёздами.

**Бездействующий игрок.** Если не двигать зоны вообще, первая миссия проигрывается на всех сидах: стартовые зоны разнесены вокруг объекта (TASK-21), и ни одна не перекрывает подступы целиком. Оставлено намеренно: перенос зон — основное действие игры, обучение первого вылета требует его вторым шагом, а при переносе зон миссия проходится с половиной прочности объекта. Проигрыш не обнуляет вылет: игрок получает утешительную награду и деньги за убийства.

## Ограничения прогонов

- Бот не покупает улучшения и не выбирает специализации: все группы уровня 0. Улучшения дают игроку запас, которого у бота нет, — прежде всего на звёзды.
- Бот не разводит группы по разным направлениям и не подменяет группу на перезарядке; сильный игрок играет лучше, слабый — хуже.
- Исход почти не зависит от сида: случаен только разброс скорости врагов.
