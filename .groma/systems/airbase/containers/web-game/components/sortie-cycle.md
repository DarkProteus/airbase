Ведёт каждую авиагруппу по фазам взлёт → полёт → патруль → возврат → перезарядка с учётом топлива и боекомплекта, принимает команды игрока (перенос зоны, отзыв на базу), применяет ауры союзникам и врагам и выбирает цели по тегам оружия, включая обнаружение малозаметных. Состав на вылет и уровни улучшений превращает в стартовое состояние групп.
