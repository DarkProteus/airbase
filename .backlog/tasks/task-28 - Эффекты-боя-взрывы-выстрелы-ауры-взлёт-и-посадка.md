## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Бой выглядит статично: выстрелы едва заметны, гибель врага — исчезновение фигурки, действие ауры Growler не видно вовсе, группы появляются над аэродромом без взлёта. Блок B этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Гибель врага сопровождается взрывом; попадания заметны
- [x] #2 Выстрелы различаются по оружию группы (данные конфига, без ветвлений по id)
- [x] #3 Зона действия ауры видна, пока её владелец патрулирует
- [x] #4 Взлёт и посадка идут по полосе аэродрома
- [x] #5 Эффекты планируются чистой функцией из событий sim, с тестом
- [x] #6 Проверено в браузере: бой держит плавную частоту кадров на последней волне
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Чистое планирование эффектов (effects.ts): взрыв, попадание, выстрел по виду оружия. 2. Круги аур (auras.ts) от снапшота через auraSources. 3. Визуальные взлёт и посадка по полосе (flight.ts). 4. Пул эффектов и отрисовка в scene.ts. 5. Тесты, npm run check, браузер и замер кадров.
<!-- SECTION:PLAN:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Эффекты боя: взрыв при гибели (вспышка, шар, кольцо, осколки, дым; размер от hp и масштаба врага), вспышка и искры попадания, два вида выстрела из данных оружия (WeaponConfig.shot: очередь трассеров для пушки, ракета с дымным следом), пульсирующий круг ауры, пока владелец патрулирует (через auraSources из sim, для любой группы с аурами), визуальные разбег, взлёт, заход и посадка по полосе аэродрома со стоянками по группам. Планирование — чистые функции с тестами (effects, auras, flight); эффекты идут из пула, не больше 160 одновременно. Проверка: npm run check зелёный; в Chromium сняты взлёт, бой, взрывы, аура, посадка, консоль чистая. Частота кадров мерилась только в headless swiftshader (около 7 кадров/с и в спокойной сцене, и на волнах 3–4; JS около 5 мс на кадр) — просадки под нагрузкой нет, но на настоящей видеокарте не проверялось. Вид оружия у события groupShot выводится по тегам цели и урону, так как индекса оружия в событии нет.
<!-- SECTION:FINAL_SUMMARY:END -->
