## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Новый игрок не знает, что зоны патрулирования можно двигать, что у групп кончается топливо и боекомплект и что истребители не бьют наземные цели. Без объяснения первый бой проигрывается без понимания причин. Блок A этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 В первом вылете игрока ведут пошаговые подсказки: выбрать группу, перенести зону, цикл топлива и перезарядки, типы целей
- [x] #2 Шаги обучения — чистый автомат состояния с тестом; шаг завершается действием игрока или событием матча
- [x] #3 Обучение можно пропустить; после прохождения или пропуска оно не показывается снова, в том числе после перезагрузки
- [x] #4 Старые сохранения читаются без потери прогресса
- [x] #5 Проверено в браузере: первый вылет с обучением и второй без него
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Чистый автомат шагов в src/ui/tutorial/machine.ts (шаги — данные) + тесты. 2. Флаг tutorialDone в профиле и сохранении (версия формата 1, поле необязательное), событие flow tutorialDone. 3. Плашка Tutorial в бою. 4. npm run check и браузер.
<!-- SECTION:PLAN:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Обучение первого вылета: плашка из шести шагов (выбрать группу, перенести зону, типы целей, топливо, перезарядка, готово). Автомат — чистая функция tutorialStep, шаг завершается действием игрока или фактом матча, на каждом шаге есть «Далее» и «Пропустить». Флаг tutorialDone хранится в профиле; старые сохранения без флага читаются целиком и видят обучение один раз. Матч обучение не меняет и не ставит на паузу. Проверка: npm run check зелёный; в Chromium пройдены полный сценарий (второй вылет без подсказок) и пропуск с перезагрузкой, консоль чистая. Решения: флаг переживает сброс прогресса; если матч закончился раньше обучения, оно считается пройденным.
<!-- SECTION:FINAL_SUMMARY:END -->
