## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В новом дизайне (design.md §5) у миссии есть цель с собственными условиями победы и поражения, а враги идут не по фиксированному пути к базе, а на цель — в том числе подвижную. Аэродром отделён от цели. Новые типы целей должны добавляться позже через данные.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Цель задаётся в MissionConfig: тип + параметры; условия победы и поражения определяются типом цели, без ветвлений по id миссии
- [ ] #2 Тест defend: победа, если объект продержался N секунд; поражение при прочности объекта ≤ 0; враги, дошедшие до объекта, наносят ему урон
- [ ] #3 Тест escort: колонна движется по маршруту из конфига; победа, когда колонна дошла до выхода; поражение, когда колонна уничтожена
- [ ] #4 Тест: враги наводятся на текущую позицию цели и меняют курс при её движении (escort)
- [ ] #5 В src/content по одной миссии на каждый тип цели, обе проходят createSim и headless-прогон до won или lost
- [ ] #6 Тест: полный headless-прогон каждой миссии детерминирован по сиду
- [ ] #7 Цель (объект, колонна, её прочность) и аэродром отображаются на карте из снапшота
<!-- AC:END -->
