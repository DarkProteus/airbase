## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Экран итога показывает только исход и сумму награды. Игрок не понимает, какая группа отработала, какая простаивала и на какой волне всё сломалось, поэтому не знает, что менять в составе и зонах. Блок A этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Sim считает по каждой группе: убийства, нанесённый урон, завершённые вылеты, долю времени в патруле
- [x] #2 Sim считает по каждой волне: сколько врагов уничтожено и сколько дошло до цели
- [x] #3 Экран итога показывает разбор по группам и волнам и выделяет слабое место (например, волну с наибольшим уроном по цели)
- [x] #4 Тест: статистика детерминирована и сходится с событиями матча
- [x] #5 Проверено в браузере: итог после победы и после поражения
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Sim ведёт статистику матча (src/sim/tally.ts): по группе — убийства, фактический урон (не больше остатка здоровья), вылеты, тики в патруле; по волне — заспавнено, сбито, дошло, урон по цели. Статистика уходит в MissionResult.stats прежним путём, store не менялся, сохранения не затронуты. Экран итога показывает таблицы по группам и волнам и слабые места (weakSpots): волна с наибольшим уроном по цели и вооружённая группа без урона или с долей патруля ниже 15%. Проверка: npm run check — 28 файлов, 276 тестов (детерминизм на одном сиде, сходимость с событиями kill/leak/spawn/sortieDone/groupShot на пяти сценариях); в Chromium проверены победа и поражение на «Эвакуации», консоль чистая. Подсветка простаивающей группы в браузере не воспроизводилась — покрыта только юнит-тестами.
<!-- SECTION:FINAL_SUMMARY:END -->
