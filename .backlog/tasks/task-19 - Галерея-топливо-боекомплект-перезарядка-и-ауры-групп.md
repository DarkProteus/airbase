## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Агенты собирают и проверяют контент в /gallery. После перехода на AirGroupConfig галерея должна показывать параметры новой модели, иначе балансировать группы придётся вслепую.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Карточка группы показывает скорость, топливо, боекомплект, время перезарядки, оружие с целевыми тегами и ауры — из конфига, без хардкода id
- [x] #2 Переключатель уровня улучшения пересчитывает эти параметры теми же функциями, что и sim
- [x] #3 Переключатель «что-если» применяет ауры других групп (например, Growler) и показывает изменение параметров
- [x] #4 Тест: галерея перечисляет ровно группы и врагов из реестров; новый конфиг появляется без правок галереи
- [x] #5 Проверено в браузере: все четыре группы и враги отображаются
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Карточка группы считает параметры через configStats (та же функция, что в sim); из sim экспортирован auraMods — галерея применяет ауры тем же таргетингом по тегам. «Что-если»: переключатели по группам-источникам аур из реестра (listAuraSources), пересчёт — чистые whatIfAuras/viewGroupWhatIf, изменение показывается как «было → стало». Браузер (headless Chromium): /gallery — 4 группы и 4 врага, уровень и Growler меняют числа (F-16 15.6 → 20.28), экран базы цел. Аура Growler на врагов (side: enemy) на карточках врагов не отображается.
<!-- SECTION:NOTES:END -->

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
