## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
У группы одно-два линейных улучшения: решения нет, всё покупается подряд за несколько вылетов. Дизайн (§2) требует, чтобы улучшения давали выбор специализации. Блок C этапа 0.2.

## Acceptance Criteria
<!-- AC:BEGIN -->

- [x] #2 На одном из уровней игрок выбирает одну из двух специализаций с разными модификаторами; выбор сохраняется в профиле
- [x] #3 Специализации заданы данными конфига; расчёт параметров идёт теми же функциями в sim, на базе и в галерее

- [x] #5 Тест: покупка, выбор ветки и итоговые параметры

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Формат: уровень улучшения может быть развилкой из двух вариантов (UpgradeConfig.options). 2. Единый расчёт: ownModifiers(cfg, level, spec) для sim, базы и галереи; spec в LineupEntry и GroupState. 3. Профиль: specs, отказ без выбора; сохранение читает необязательное поле. 4. Контент: по 3 уровня и одной развилке у шести групп. 5. UI базы, галереи, панели боя. 6. Тесты, npm run check, браузер.
<!-- SECTION:PLAN:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
У всех шести групп по три уровня улучшений и одна развилка из двух специализаций, заданных данными (UpgradeConfig.options). Модификаторы уровня и выбранной ветки считает одна функция ownModifiers(cfg, level, spec) — ею пользуются sim, карточка базы и галерея; выбор доезжает до боя через LineupEntry.spec и GroupState.spec. Выбор хранится в Profile.specs (необязательное поле, версия сохранения 1); покупка развилки без выбора отклоняется без списания валюты. Первые уровни и цены прежние, поэтому старое сохранение с максимальными уровнями стоит перед развилкой; купленная развилка без выбора трактуется как первый вариант. База показывает два варианта с изменениями параметров и кнопкой выбора, галерея — переключатель ветки, панель боя — название специализации. Проверка: npm run check зелёный (506 тестов); в Chromium выбран «Охотник» у F-16, выбор пережил перезагрузку, в бою боекомплект веток отличается (110 против 86), старое сохранение читается, консоль чистая. Смены специализации после покупки нет; баланс веток на глаз — TASK-35.
