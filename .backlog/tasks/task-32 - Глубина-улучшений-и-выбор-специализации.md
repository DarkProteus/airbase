## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
У группы одно-два линейных улучшения: решения нет, всё покупается подряд за несколько вылетов. Дизайн (§2) требует, чтобы улучшения давали выбор специализации. Блок C этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 У каждой группы 3–4 уровня улучшений
- [ ] #2 На одном из уровней игрок выбирает одну из двух специализаций с разными модификаторами; выбор сохраняется в профиле
- [ ] #3 Специализации заданы данными конфига; расчёт параметров идёт теми же функциями в sim, на базе и в галерее
- [ ] #4 Старые сохранения читаются: купленные уровни не теряются
- [ ] #5 Тест: покупка, выбор ветки и итоговые параметры
- [ ] #6 Проверено в браузере: улучшение с выбором на базе и его эффект в бою
<!-- AC:END -->
