## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
npm run balance гоняет только составы без улучшений и показывает лишь победы. Ночной разбор 2026-11-16 (docs/balance-0.2.md, раздел «Ночной разбор») делался разовым скриптом на двух сидах и в репозиторий не вошёл; без этих таблиц задачи по F-16, C-130, KC-135, улучшениям и врагам нечем проверять. Метод: тот же бот (botZone), для улучшений — состав уровня 0, где одна группа поднята до проверяемого уровня и специализации; статистика групп — из state.stats, врагов — из событий spawn/kill/leak.
