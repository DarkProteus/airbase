## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Итог TASK-45: улучшения KC-135 больше не отнимают побед, но прирост каждого уровня ниже порога — максимум 1 новая пара / +0,16 пп (нужно ≥2 пары или ≥2 пп). ~90 вариантов (бак, аура топлива, перезарядка, скорость заправщика) дали не больше 1 пары / 0,38 пп за уровень. Причина: 51 из 60 составов с KC-135 решает огневая мощь, а не топливо; заправщик помогает только группам, которые уходят по топливу (F-16, Growler, E-3), и лишь сдвигает момент их единственного возврата (механизм: burn = own.fuel / st.fuel в stepGroups, src/sim/sortie.ts). Нужно, чтобы топливо реально ограничивало вылеты: базовые баки/расход групп, длина миссий или волны — так, чтобы время патруля решало исход. Связано с TASK-52 (у E-3 та же проблема — рычаг поддержки насыщен). Боевые баффы заправщику не давать.
