## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Миссии не связаны между собой, копить валюту незачем, у сессии нет цели дальше одного боя. Сюда же отнесены открытые вопросы MVP: награда за поражение и бонус за сохранённую цель. Блок D этапа 0.2.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Миссии идут цепочкой: следующая открывается после победы в предыдущей
- [ ] #2 За победу даётся 1–3 звезды по остатку прочности цели; лучший результат по миссии сохраняется
- [ ] #3 Награда за первое прохождение и за новые звёзды больше, чем за повтор; правило награды за поражение зафиксировано в `docs/design.md`
- [ ] #4 Расчёт звёзд и награды — чистые функции в sim с тестами; награда начисляется ровно один раз
- [ ] #5 Формат сохранения версии 2; сохранение версии 1 мигрирует без потери валюты, групп и состава
- [ ] #6 Проверено в браузере: прохождение двух миссий подряд, перезагрузка, прогресс на месте
