## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Баланс этапа 0.2 проверен полным headless-прогоном (6 миссий × 20 составов × 5 сидов) и исправлен в конфигах. Ни один состав не выигрывает больше 4 миссий из 6; каждая группа входит в выигрышные составы, ни одна не обязательна везде. Стартовый состав F-16+A-10+C-130 проходит первую миссию без покупок (5/5, 50% прочности) при переносе зон. Один проход кампании даёт ~2200 валюты: все группы (360) и ~66% улучшений (2800). Отчёт — docs/balance-0.2.md (npm run balance), условия сторожит src/content/balance.test.ts; design.md обновлён. Проверка: npm run check — 538 тестов. Риски: бот не покупает улучшений и играет проще человека; существующие сохранения стартовый профиль не получают (у них свой состав и валюта).
