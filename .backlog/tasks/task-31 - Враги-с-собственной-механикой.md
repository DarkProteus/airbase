## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Четыре врага различаются только здоровьем, скоростью и тегом воздух или земля, поэтому состав на вылет почти не зависит от волн. Нужны враги, которые требуют конкретного ответа и дают смысл поддержке. Блок C этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Бронированный враг: слабые попадания почти не наносят урона, тяжёлое оружие пробивает
- [x] #2 Малозаметный враг: группы атакуют его только в зоне действия группы обнаружения (ДРЛО)
- [x] #3 Носитель: при гибели выпускает нескольких мелких врагов
- [x] #4 Каждое свойство — общее поле конфига врага или тег, пригодные для любого врага; в sim нет ветвлений по id
- [x] #5 Sim остаётся детерминированным; новые свойства покрыты тестами
- [x] #6 Новые враги видны в галерее со своими параметрами и появляются в бою
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Три общих свойства врага в конфиге. armor: попадание теряет armor урона, но проходит не меньше 10%. stealth: враг становится мишенью только в зоне вражеской ауры со статом detect (её получил E-3). spawnOnDeath: при гибели выпускает count врагов заданного типа на своём месте (в счётчик своей волны, событие spawn с полем from). В sim нет ветвлений по id. Новые враги: ударный вертолёт (armor 10, теги air+low — пушка F-16 снимает 2 из 12, ракета A-10 35 из 45; A-10 теперь бьёт и тег low), малозаметный БПЛА, носитель дронов (4 дрона). У каждого своя модель. Разметка: необнаруженный малозаметный враг тусклый, в предупреждении о волне «бить некому», если в составе нет группы обнаружения. Проверка: npm run check зелёный (384 теста, включая детерминизм на одном сиде); в Chromium новые враги видны в галерее с параметрами и в бою. В существующих миссиях новых врагов нет — в бою проверены подстановкой волны на странице; в миссии их ставит TASK-33.
