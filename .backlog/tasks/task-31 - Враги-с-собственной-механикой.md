## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Четыре врага различаются только здоровьем, скоростью и тегом воздух или земля, поэтому состав на вылет почти не зависит от волн. Нужны враги, которые требуют конкретного ответа и дают смысл поддержке. Блок C этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Бронированный враг: слабые попадания почти не наносят урона, тяжёлое оружие пробивает
- [ ] #2 Малозаметный враг: группы атакуют его только в зоне действия группы обнаружения (ДРЛО)
- [ ] #3 Носитель: при гибели выпускает нескольких мелких врагов
- [ ] #4 Каждое свойство — общее поле конфига врага или тег, пригодные для любого врага; в sim нет ветвлений по id
- [ ] #5 Sim остаётся детерминированным; новые свойства покрыты тестами
- [ ] #6 Новые враги видны в галерее со своими параметрами и появляются в бою
<!-- AC:END -->
