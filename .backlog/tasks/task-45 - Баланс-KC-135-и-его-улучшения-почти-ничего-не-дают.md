## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Причина ухудшения (AC1): аура топлива KC-135 растягивает вылет только групп, которые уходят по топливу (F-16, Growler, E-3), — burn = own.fuel / st.fuel в stepGroups (src/sim/sortie.ts). Возврат у F-16 один за матч и с улучшением, и без; улучшение лишь сдвигает его. Пример: «Укрепрайон», F-16 + A-10 + KC-135, сид 1 — без улучшений F-16 возвращается на 78,8 с (затишье, утечек нет), победа с остатком 5 hp; со старым ур. 3 «Усиленная заправка» — на 103,2 с, окно приходится на волну (8 попаданий, 22 → 15 hp), объект разрушен к 145,7 с; 5/5 → 3/5. В свежем отчёте потерю давал только ур. 3, не ур. 2. AC2 НЕ выполнен: прирост за уровень максимум 1 пара / +0,16 пп (~90 вариантов, лучший 1 пара / 0,38 пп), 51 из 60 составов решает огневая мощь. По решению пользователя задача закрыта с невыполненным AC2, продолжение — TASK-53.
