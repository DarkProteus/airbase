## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Экономика переезжает из боя на базу (design.md §1, §5): между миссиями игрок покупает и улучшает авиагруппы за заработанную валюту и выбирает три из них на вылет. Правила цен и уровней из TASK-9 переиспользуются, а не пишутся заново.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Профиль игрока (валюта, купленные группы, их уровни, выбранный состав) и операции над ним — чистый модуль без React/Zustand/Three, стартовый профиль задан данными
- [ ] #2 Тест: покупка и улучшение списывают валюту; отказ при нехватке, повторной покупке и максимальном уровне
- [ ] #3 Тест: в состав можно выбрать только купленные группы, ровно 3; вылет недоступен при неполном составе
- [ ] #4 Тест: уровень улучшения меняет боевые параметры группы в бою (модификаторы уровней из конфига)
- [ ] #5 Экран строится из реестра групп универсальной карточкой; недоступные действия отключены, причина отказа показана
- [ ] #6 В браузере: купить группу, улучшить её, собрать состав из 3
