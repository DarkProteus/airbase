Все четыре группы и четыре врага получили свои низкополи-модели, заданные только данными (6–14 деталей, цвет сущности плюс акценты): F-16, A-10 с двумя двигателями, Growler с двумя килями, четырёхмоторный C-130, квадрокоптер-дрон, винтовой разведчик, танк с башней, бомбардировщик. Бандл main вырос с 824.40 до 845.38 кБ (+2.5%, вместе с окружением TASK-27). Проверка: npm run check зелёный; в Chromium сняты галерея, база и бой. Бомбардировщика нет ни в одной миссии — в бою он проверен только подстановкой волны на странице.
