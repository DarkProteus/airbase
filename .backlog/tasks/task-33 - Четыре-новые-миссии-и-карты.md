## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Миссий две, обе на одной карте 13×11 с четырьмя волнами: после нескольких вылетов играть не во что. Блок C этапа 0.2.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Миссий шесть; новые отличаются размером карты, положением аэродрома, числом точек входа и длиной (6–8 волн)
- [ ] #2 Типы целей прежние (defend, escort); новые миссии заданы только данными
- [ ] #3 В новых миссиях встречаются враги с механиками; хотя бы в двух миссиях выгоден разный состав
- [ ] #4 Стартовые зоны патруля осмысленны на каждой карте
- [ ] #5 Тест: каждая миссия проходима ботом хотя бы одним составом и не проходима составом без нужного типа оружия
- [ ] #6 Проверено в браузере: каждая новая миссия запускается и доигрывается до итога
<!-- AC:END -->
