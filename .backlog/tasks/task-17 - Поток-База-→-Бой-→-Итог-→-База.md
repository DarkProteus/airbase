## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сессия должна замыкаться в цикл (design.md §1): с базы игрок уходит в миссию с выбранным составом, получает итог и награду и возвращается на базу тратить её. Заменяет архивную TASK-11 в части экрана победы/поражения.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 С базы выбирается миссия (defend или escort) и запускается бой с выбранным составом и уровнями групп
- [x] #2 По завершении боя показан экран итога: победа или поражение по цели миссии, статистика и награда (с бонусом C-130)
- [x] #3 Тест: награда за миссию считается чистой функцией из результата матча и начисляется в профиль ровно один раз
- [x] #4 С экрана итога — возврат на базу; повторный вылет создаёт новый матч с новым сидом без перезагрузки страницы
- [x] #5 Тест: переходы между экранами (база, бой, итог) — чистая функция состояния; из боя нельзя попасть на базу без итога
- [x] #6 В браузере пройден полный круг: база → бой → итог → база, валюта выросла
