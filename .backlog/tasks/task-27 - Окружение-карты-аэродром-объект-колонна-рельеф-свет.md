## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Окружение карты из MissionConfig: аэродром с полосой, ангаром, вышкой и цистернами; цель — здание-штаб (defend) или колонна из четырёх машин, едущая по дороге маршрута (escort); входы врагов — красные ворота со стрелкой внутрь карты; земля с пятнами травы, деревьями, камнями и холмами за краем; направленный свет с тенями. Раскладка — чистые детерминированные функции (хеш от координат), декор не попадает на аэродром, входы, цель и дорогу; ветвление только по типу цели. Проверка: npm run check зелёный; в Chromium сняты обе миссии (начало, середина, бой), клик по карте по-прежнему переносит зону, консоль чистая. Sim, MissionConfig и миссии не менялись.
