## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Владелец проекта после игры: враги идут к цели по прямой, карта на бой не влияет, зоны всегда ставятся вплотную к цели. Решение владельца (2026-11-15): рельеф становится преградой — наземные враги обходят горы и воду, воздушные обходят только высокие хребты, над водой и холмами летят прямо. Так появляются проходы и узкие места, которые выгодно перекрывать зонами. Сейчас рельеф — только декорация рендера (TASK-27).
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. sim/terrain.ts: рельеф как данные миссии (MissionConfig.terrain — строки-карта: '.' свободно, '~' вода, '^' горы, '#' хребет), таблица проходимости по классу движения (ground по тегу / air), поле расстояний до клетки цели, проверка прямой видимости, путевые точки, маршрут-полилиния, проверка связности.
2. engine: враги идут по прямой, пока цель видна, иначе по путевым точкам поля; поле пересчитывается при смене клетки цели; createSim отвергает отрезанные базы/маршрут.
3. bot: направление выноса зоны — по маршруту врага, а не по прямой.
4. content: рельеф минимум в трёх миссиях, тест контента (связность + отрицательный пример), перенастройка баланса, npm run balance.
5. render/ui: меши воды, гор и хребтов из тех же данных; декор их обходит; маршруты ближайшей волны линиями на карте.
6. docs/design.md, npm run check.

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Рельеф миссии стал данными sim (MissionConfig.terrain): наземные враги обходят воду и горы, все — хребты; путь детерминирован и пересчитывается за колонной. Движок и тест контента отвергают миссии с отрезанной базой или перекрытым маршрутом. Рельеф есть во всех шести миссиях, рендер рисует его из тех же данных, маршруты ближайшей волны и легенда показаны на карте, бот выносит зоны вдоль маршрута. Проверка: npm run check — 626 тестов; карты просмотрены на скриншотах headless Chromium. Баланс: числа не менялись, условия balance.test.ts выполняются; у «Укрепрайона» и «Речного каравана» стало на один выигрышный состав меньше (см. docs/balance-0.2.md). Замечания вынесены в отдельные задачи: высокие хребты заслоняют клетки позади себя, вертолёт (высота 0,55) визуально летит сквозь вершины гор (до 0,62).
