## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Кор-геймплей сменился (design.md §1, §5): самолёты не турели, группа взлетает с аэродрома на краю карты, летит в зону, патрулирует, пока хватает топлива и боекомплекта, возвращается и перезаряжается. Это основа всех остальных задач нового дизайна. Старая турельная модель (слоты, покупка в бою) сохранена тегом v0-turret; на этом шаге она может сосуществовать с новой — её удаление входит в задачу перевода юнитов на AirGroupConfig.
<!-- SECTION:DESCRIPTION:END -->

- [x] #4 Тест: время перелёта = расстояние / скорость; чем дальше зона от аэродрома, тем меньше времени группа проводит в зоне за вылет

- [x] #8 Тест: два прогона с одним сидом дают идентичный снапшот; src/sim по-прежнему без импортов three/react/zustand

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Решения: топливо — секунды полёта на весь вылет; группа уходит на возврат по «бинго» (остатка хватает только до аэродрома), поэтому время в зоне = fuel − 2·расстояние/скорость. Боекомплект общий на всё оружие; группа без боекомплекта (ammo 0) из-за него не возвращается. Оружие бьёт врага с любым из targetTags (пустой список — любого). Длительность взлёта вынесена в конфиг (takeoffTime), радиус зоны — zoneRadius (стат range). Content.groups пока опционален, MissionConfig.airfield обязателен. Не сделано намеренно: межгрупповые ауры (TASK-15), команда переноса зоны (TASK-13), отображение групп (TASK-13/14) — в игре групп пока не видно, driver состав не передаёт.
<!-- SECTION:NOTES:END -->
