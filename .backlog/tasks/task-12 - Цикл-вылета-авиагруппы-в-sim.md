## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Кор-геймплей сменился (design.md §1, §5): самолёты не турели, группа взлетает с аэродрома на краю карты, летит в зону, патрулирует, пока хватает топлива и боекомплекта, возвращается и перезаряжается. Это основа всех остальных задач нового дизайна. Старая турельная модель (слоты, покупка в бою) сохранена тегом v0-turret; на этом шаге она может сосуществовать с новой — её удаление входит в задачу перевода юнитов на AirGroupConfig.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Экспортируется тип AirGroupConfig (роль, теги, скорость, топливо, боекомплект, время перезарядки, оружие с целевыми тегами, аура-модификаторы); аэродром задан в MissionConfig и лежит на краю карты
- [ ] #2 Состав на вылет (группы, уровни, стартовые зоны) передаётся при создании матча; команд покупки групп в бою нет
- [ ] #3 Тест: группа проходит фазы взлёт → перелёт → патруль → возврат → перезарядка → снова, длительности берутся из конфига
- [ ] #4 Тест: время перелёта = расстояние / скорость; чем дальше зона от аэродрома, тем меньше времени группа проводит в зоне за вылет
- [ ] #5 Тест: группа уходит на возврат при исчерпании топлива или боекомплекта; после перезарядки оба ресурса восстановлены
- [ ] #6 Тест: группа атакует только в фазе патруля и только врагов внутри своей зоны; каждый выстрел расходует боекомплект
- [ ] #7 Тест: событие завершённого вылета (группа вернулась на аэродром) попадает в события sim
- [ ] #8 Тест: два прогона с одним сидом дают идентичный снапшот; src/sim по-прежнему без импортов three/react/zustand
<!-- AC:END -->
