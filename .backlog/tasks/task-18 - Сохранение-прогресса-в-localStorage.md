## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Прогресс базы (валюта, группы, уровни, состав) должен переживать перезагрузку, иначе цикл «заработал — потратил» теряет смысл. Игра будет опубликована на github.io, где localStorage общий для всех проектов домена. Заменяет архивную TASK-11 в части сохранения.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria

- [x] #4 Формат сохранения версионирован; ключ хранилища с префиксом airbase:

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Чистые serializeProfile/parseProfile в src/sim/save.ts (формат {version:1, profile}, строгая валидация; устаревшие группы отбрасываются поштучно), доступ к хранилищу — src/ui/save.ts, ключ airbase:save. Единственная точка записи — send() в src/ui/flow.ts по смене профиля. Сброс — двухшаговая кнопка на базе (чистый resetStep), через событие profile. Браузер (headless Chromium): покупка → перезагрузка → профиль на месте; мусор/версия 99 → стартовый профиль; сброс с подтверждением переживает перезагрузку.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Профиль сохраняется в localStorage (airbase:save, версия 1) при каждом изменении и восстанавливается при запуске; повреждённое/устаревшее/недоступное хранилище даёт стартовый профиль; сброс прогресса с подтверждением. check: 25 файлов, 216 тестов; перезагрузка проверена в браузере.
