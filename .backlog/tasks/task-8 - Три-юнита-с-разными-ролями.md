## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
MVP §5 п.3: универсальный истребитель, юнит поддержки с необычной механикой, экономический/инфраструктурный юнит (ориентиры — design.md §2). Юниты должны отличаться механикой, а не числами; синергии — теги + модификаторы.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Три юнита описаны TS-конфигами; новое поведение выражено тегами/модификаторами, без ветвлений по id юнита в движке
- [ ] #2 Тест: истребитель выбирает цель в радиусе и наносит урон с заданным темпом
- [ ] #3 Тест: юнит поддержки сам почти не наносит урон, но измеримо усиливает союзников в зоне (синергия через модификатор)
- [ ] #4 Тест: экономический юнит даёт доход/бонус между волнами
- [ ] #5 Тест (headless): на эталонной миссии ни один моно-состав не выигрывает лучше смешанного
- [ ] #6 Все три юнита видны и проверены в /gallery
