## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Владелец проекта после игры на опубликованной версии: главная трудность боя — группы сами уходят на перезарядку ровно тогда, когда пошла волна. Игрок видит остаток топлива и боекомплекта, но повлиять не может: возврат наступает только по исчерпанию. Нужна возможность отправить группу на базу заранее, в паузе между волнами, чтобы к волне она вернулась заправленной. В docs/design.md «ручные приказы в бою» записаны вне этапа 0.2 — владелец это решение пересмотрел для этого приказа.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria

- [x] #2 Отправленная группа сразу летит на аэродром, заправляется и перезаряжается как после обычного вылета и сама вылетает снова в свою зону

- [x] #5 Обучение первого вылета упоминает кнопку; docs/design.md отражает появление приказа
- [x] #6 npm run check проходит

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Команда recall в sim: проверка recallRejection (перелёт/патруль), событие recalled, причина отказа notAirborne
2. Кнопка «На базу» в панели групп, доступность из той же проверки sim
3. Прерванный вылет без бонуса income
4. Текст обучения, design.md, тесты
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Критерий про бонус изменён по ходу: сначала было «засчитывается как обычный вылет», но тогда отзыв сразу после взлёта давал бы C-130 доход каждые ~9 с. Прерванный вылет идёт в счётчик вылетов, income не начисляется. Кнопка проверена скриншотом боя (headless Chromium): видна, на взлёте выключена. Нажатие в браузере не прогонялось — путь команды покрыт тестами sim и селекторов. Headless-бот приказ не использует, баланс прогонов не изменился.
<!-- SECTION:NOTES:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Добавлен приказ recall: кнопка «На базу» у каждой группы в бою отправляет её на аэродром досрочно; после перезарядки группа сама вылетает в ту же зону. Команда и проверка — в sim (recallRejection, событие recalled, отказ notAirborne), UI только вызывает. Прерванный вылет не приносит бонус за вылет. Обучение и design.md обновлены. npm run check — 548 тестов; вид кнопки проверен скриншотом, клик в браузере вручную не проверялся.
