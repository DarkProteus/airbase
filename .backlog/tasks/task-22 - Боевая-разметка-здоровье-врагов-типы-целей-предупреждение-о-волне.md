## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
В бою не видно, сколько здоровья у врага, воздушный он или наземный, кто по кому стреляет и откуда придёт следующая волна. Игрок двигает зоны вслепую и не понимает, почему группа не атакует цель. Блок A этапа 0.2 (понятность боя).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 У каждого врага в бою видна полоска здоровья, убывающая при попаданиях
- [x] #2 Враги и оружие групп помечены типом цели (воздух или земля) из тегов конфига, без ветвлений по id; видно, какая группа может бить какого врага
- [x] #3 Перед волной игрок видит предупреждение: через сколько секунд, из каких точек входа и какой состав
- [x] #4 При стрельбе видно, какая группа атакует какую цель
- [x] #5 Тест: данные разметки (полоски, типы, предупреждение) — чистые функции от снапшота sim и конфигов
- [x] #6 Проверено в браузере: бой с волной воздушных и наземных врагов
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Боевая разметка: полоски здоровья и метки типа (ромб — воздух, квадрат — земля) над врагами, затемнение врагов, недоступных выбранной группе, луч и трассер цвета группы до цели, панель предупреждения о волне (секунды, входы, состав, кто может бить) с кольцами на точках входа. Данные — чистые функции в src/ui/game/markup.ts от снапшота и конфигов; в sim добавлены GroupState.lastShot и weaponHits (общее правило для стрельбы и разметки). Проверка: npm run check — 27 файлов, 242 теста; бой в Chromium на миссии «Эвакуация» (волны с бронетехникой и дронами), консоль чистая. Ограничения: типы целей только air/ground; предупреждение показывается в фазе подготовки и при ожидании зачистки, первая волна предупреждает за 5–6 с (её prep).
