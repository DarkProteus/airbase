## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
DEFAULT_ZONES разнесены вокруг объекта: (3,4), (6,7), (7,4). Побочный эффект: без команд игрока «Эвакуация» с F-16+A-10+Growler теперь проигрывается (раньше выигрывалась с объектом 6/20 без единого клика); «Колонна» без команд проигрывалась и раньше. Тест перезарядки в selectors.test.ts больше не зависит от стартовых зон. Подсказка управления видна всегда; строка боекомплекта скрывается при 0; карточки базы растянуты по высоте ряда. Браузер (headless Chromium, dev): 4 карточки по 332px, у Growler и C-130 нет строки боекомплекта, в бою группы разведены, подсказка видна, ошибок консоли нет. Группы патрулируют внутри зоны, поэтому фигурка может проходить рядом с объектом.
