## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
База, HUD боя и экран итога оформлены как отладочные панели, звук — синтезированные писки. После обновления сцены интерфейс выбивается из картинки. Блок B этапа 0.2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 База, HUD боя, итог и обучение оформлены в одном стиле: общие шрифт, цвета, панели, кнопки
- [x] #2 У ролей групп есть значки, одинаковые на базе, в бою и в галерее
- [x] #3 Звуки выстрелов, попаданий, гибели врага, тревоги волны и исхода миссии различимы на слух; mute по-прежнему работает и сохраняется
- [x] #4 Интерфейс не ломается на ширине окна от 960 px
- [x] #5 Проверено в браузере: база, бой, итог
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Единая тема src/ui/theme.css и перевод всех экранов на неё. 2. Значки ролей: таблица и компонент RoleIcon. 3. Звук: новые синтезированные голоса, троттлинг, лимитер. 4. Проверка на 960 и 1280, npm run check.
<!-- SECTION:PLAN:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Единая тема (theme.css: переменные цветов, панели, кнопки, теги, полоски) для базы, HUD боя, итога, обучения и галереи; HUD стал панелью с ячейками. Значки ролей — таблица роль→SVG с запасным значком, один компонент RoleIcon на базе, в бою и в галерее. Звук: разные синтезированные голоса для пушки, ракеты, гибели врага, удара по цели, тревоги перед волной, старта волны, победы и поражения; троттлинг очередей, лимитер и ограничение числа источников; вид выстрела берётся из WeaponConfig.shot. Mute работает и сохраняется после перезагрузки. Проверка: npm run check зелёный; в Chromium на 960×720 и 1280×800 сняты база, бой, итог, галерея — без горизонтальной прокрутки и наложений, консоль чистая; создание нужных аудиоузлов и mute проверены перехватом AudioContext. На слух звук не проверялся.
<!-- SECTION:FINAL_SUMMARY:END -->
